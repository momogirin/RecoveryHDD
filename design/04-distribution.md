# 04. 배포 계획 (맥용 / 윈도우용 따로)

핵심 제약: **원본 디스크를 직접 읽으려면 두 OS 모두 관리자 권한이 필요하다.** 그래서 "권한을 받는 시작 방식"만 OS별로 다르고, 엔진·서버·화면은 같다.

## 맥용
| 단계 | 방식 | 상태 |
|---|---|---|
| 지금 | `launch/mac/RecoveryTool.command` 더블클릭 → macOS 비밀번호 창 → 브라우저가 자동으로 열림 | 구현됨. 관리자 창만 뺀 사본으로 인자 전달·서버 시작·주소 추출·종료를 확인함. **비밀번호 창 자체는 실제로 눌러 보지 않음** |
| 이후 | `.app` 으로 포장(py2app 또는 PyInstaller) | 미구현 |
| 배포 | 서명·공증 없이 배포하면 처음 열 때 "확인되지 않은 개발자" 경고가 뜬다(우클릭 → 열기로 우회). 경고 없이 배포하려면 Apple Developer 계정(유료)으로 서명·공증이 필요하다 | 미정 |

- Python 3 가 필요하다. `.app` 으로 포장하면 사용자가 따로 설치하지 않아도 된다.
- 실행 중 맥이 잠자기에 들어가지 않도록 `caffeinate` 로 감싼다(구현됨).

## 윈도우용
| 단계 | 방식 | 상태 |
|---|---|---|
| 1 | 윈도우용 장치 읽기: `\\.\PhysicalDriveN@파티션시작`, 4096 바이트 정렬 읽기(`blockdev.py`), GPT 직접 해석(`gpt.py`, CRC 불일치 시 추측하지 않음) | **구현됨.** 가짜 이미지로 정렬·오프셋·GPT(512/4096 섹터)를 테스트. 실제 물리 디스크 읽기는 관리자 권한 + 실제 외장 디스크가 필요해 **미확인**. 관리자가 아닐 때는 `PermissionError`(안내 문구 표시)임을 확인 |
| 2 | 외장 디스크 목록(`Get-Disk`/`Get-Partition`, `devices.py`) | **구현됨.** 이 PC에서 실제 조회 확인. 시스템/부팅 디스크와 NVMe/SATA 등 내장 버스는 기본 숨김(`--all-disks` 로 표시). 같은 디스크의 다른 드라이브 문자에는 저장 금지. 3초 캐시. APFS 가 붙은 실제 외장 디스크로는 **미확인** |
| 3 | **프로그램(`dist\RecoveryTool.exe`, 약 18MB)**: 더블클릭 → Windows 관리자 확인 창 → 전용 창(WebView2)에 화면이 열림. 창을 닫거나 [도구 종료]를 누르면 끝난다. 작업 중에는 창이 닫히지 않는다 | **구현·빌드됨.** `launch\windows\build_exe.ps1` 로 만든다(파이썬/Pillow 포함 단일 파일). 관리자 확인이 없는 시험용 사본(`RT_BUILD_NOADMIN=1`)으로 전용 창 생성(제목·크기), 화면 렌더링(스크린샷), 서버 응답, 종료 후 프로세스 정리를 확인. 실제 exe 에는 `requireAdministrator` 가 들어간 것을 확인. **관리자 확인 창 자체는 실제로 눌러 보지 않음** |
| 4 | `RecoveryTool.bat` | 개발용 보조 수단. 사용자는 exe 를 쓴다. `.bat` 는 영문만 쓴다(한글 줄은 cmd 가 잘못 읽음) |
| 배포 | `.exe` 는 **윈도우에서 빌드**해야 한다(맥에서 만들 수 없다). 서명이 없으면 SmartScreen 경고가 뜬다 | 미정 |

- 윈도우는 APFS 를 읽지 못하므로 볼륨이 마운트되지 않는다. 디스크 전체(`PhysicalDriveN`)를 직접 읽어야 한다.
- **실제 외장 디스크로 읽기 정렬·권한을 실측해야** 하며, 그 전에는 동작을 보장하지 않는다. 개인 PC 에서 먼저 실측하고 회사 PC 는 나중에 본다(`01-plan.md` 7절).
- 전용 창은 **WebView2 런타임**이 필요하다(Windows 11 에는 기본 설치). 없으면 자동으로 기본 브라우저로 연다.
- 서명이 없는 exe 는 처음 실행할 때 SmartScreen 경고("PC 보호" → 추가 정보 → 실행)가 뜰 수 있다.
- 윈도우는 APFS 를 모르므로 디스크를 꽂으면 **"초기화/포맷하세요"** 라고 물을 수 있다. 절대 누르면 안 된다. 실행 시 안내 문구를 출력한다.
- 사진 열림 검사(디코딩)는 Pillow 가 있어야 한다: `py -3 -m pip install pillow`. 없으면 구조 검사까지만 하고 그렇게 표시한다(맥은 `sips` 로 대신 함).
- 윈도우 전용으로 고친 것: `os.pread` 없음 → seek+read, 프로세스 확인(`os.kill` 은 윈도우에서 프로세스를 죽임) → `OpenProcess`, 상태 파일 교체 시 `액세스 거부` 재시도, 인코딩 UTF-8 고정(한국어 윈도우 기본은 cp949), 잠자기 방지(`SetThreadExecutionState`), 배터리 확인(`GetSystemPowerStatus`), 윈도우 폴더 이름 규칙, 드라이브 빠른 위치.

## 공통
- 화면의 **도구 종료** 버튼으로 관리자 권한 프로세스를 끈다(작업 중에는 거부).
- 서버는 `127.0.0.1` 에서만 열리고 실행마다 새 토큰을 쓴다.
- 읽기 전용 원칙 검사는 소스 전체에 대한 테스트로 자동화되어 있다(`tests/test_safety.py`).
